# Family Fitness AI

A private two-profile fitness and nutrition PWA.

## Prototype features
- Ivan and Wife profiles
- Daily calorie and protein tracking
- Water tracking
- Workout logging
- Weight history
- Browser voice-to-text where supported
- Local device storage
- Installable/offline PWA foundation

## Next phase
Add secure authentication, synchronized cloud database, and server-side OpenAI API integration. Never place an OpenAI API key directly in browser code.
